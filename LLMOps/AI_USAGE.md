# AI 사용 기록

AI는 개념 설명과 직접 작성한 코드의 오류 원인 확인에 사용할 수 있습니다. 과제 전체, 미작성 TODO, 프롬프트 문장, 선택 심화 설계를 대신 완성하도록 요청하지 않습니다.

사용하지 않았다면 아래에 사용하지 않음이라고 적습니다. 사용했다면 필요한 만큼 항목을 추가하세요. API 키나 개인정보는 기록하지 않습니다.

- 사용 도구: ChatGPT (Codex)
- 질문한 내용: 전화번호 마스킹, JSON 및 출처 검증, 관측 필드 구성, 사례 평가, 지표 집계, 변경 판단의 TODO를 채우는 코드와 주석 예시를 요청했습니다. `strip()`과 `parsed.action`의 의미, 개선 지시문에 들어갈 네 규칙과 반환 위치, `uv`가 `pyproject.toml`이나 `main.py`를 찾지 못한 원인, 코드의 전체 흐름과 LLMOps 개념도 물었습니다.
- 이해한 내용: `strip()`을 적용한 결과가 빈 문자열이면 빈 답변이나 공백만 있는 답변을 거절합니다. `parsed.action`은 답변·보류·거절 중 모델이 선택한 처리 유형입니다. 답변 검증에서는 실제 출처가 허용 목록의 부분집합인지 확인하고, 사례 평가에서는 실제 출처 집합이 기대 출처 집합과 일치하는지 확인합니다. 미응답 피드백은 긍정 비율의 분모에서 제외하고, 비용이 하나라도 누락되면 합계는 `None`으로 둡니다. 후보의 통과 수가 늘어도 중요 사례가 실패하면 변경을 보류합니다.
- 직접 수정한 부분: 일부 주석은 직접 작성하겠다고 했고, Codex가 파일에 적용한 변경은 원상복구를 요청했습니다. 이후에는 원본 파일을 그대로 두고 TODO 코드와 주석 예시를 대화에서 보여 달라고 요청했습니다.
- 다시 실행한 명령과 확인 결과: 기존 `uv run --frozen python main.py check all` 결과 파일에서 30개 항목이 모두 통과한 것을 확인했습니다. 고정 응답 비교 결과는 기준선 2/4, 후보 3/4, `approve=false`였습니다. 이 기록을 작성하면서 검사를 다시 실행하지 않았습니다.
