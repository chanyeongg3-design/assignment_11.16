# AI 사용 기록

AI는 개념 질문과 직접 작성한 코드의 오류 원인 확인에 사용할 수 있습니다. 과제 전체, 미작성 빈칸, 선택 심화의 설계나 정답을 대신 작성하도록 요청하지 않습니다. 설명을 이해한 뒤 직접 수정하고 다시 검사하세요.

사용하지 않았다면 아래에 사용하지 않음이라고 적습니다. 사용했다면 필요한 만큼 행을 추가하세요. API 키와 개인 정보는 기록하지 않습니다.

| 사용 도구 | 질문 | 이해한 내용 | 직접 수정한 부분 | 다시 실행한 명령과 결과 |
|---|---|---|---|---|
| ChatGPT(Codex) | 필수 1을 완료한 예전 코드가 어디에 있는지 찾고 다시 실행해 달라고 요청 | 자료 선택, 메시지 조립, 사용자별 기억 관리가 필수 1을 구성한다는 점을 확인했다. 기억을 읽을 때 복사본을 반환해야 원본이 바뀌지 않는다. | AI가 이전 대화에 남아 있던 세 함수를 별도 복구본으로 추출했다. 현재 작업본의 기억 조회에는 `copy.deepcopy`가 적용되어 있다. | `run context`, `run memory` 예제 실행 성공. `check context` 5/5, `check memory` 4/4 통과. |
| ChatGPT(Codex) | `fact_lines`의 역할과 `summarize`의 TODO 코드 요청 | `fact_lines`가 지정된 항목과 값을 꺼내며, 같은 항목을 나중에 다시 저장하면 최신 값과 출처 턴이 함께 남는다는 점을 이해했다. | AI가 `value`와 `source_turn_id`를 저장하는 완성 코드를 채팅으로 제시했다. 현재 작업본에 이 방식이 반영되어 있다. | `check compare` 4/4 통과. |
| ChatGPT(Codex) | `validate_budget`, 예산 계산과 초과 조건, 압축 비교 결과 설명 요청 | 전체 한도에서 출력 예약량과 여유분을 빼면 입력 예산이 된다. 후보 턴을 붙인 전체 메시지의 토큰 수가 예산보다 클 때만 반복을 멈춘다. | AI가 예산 계산 줄을 파일에 넣었다가 요청에 따라 원래 TODO로 되돌렸다. 초과 조건과 관측 주석 문구는 채팅에서 도움을 받았다. 현재 작업본에 계산식, 초과 조건과 관측 주석이 반영되어 있다. | `run compare` 및 `run compare --live` 결과 확인. 추정 입력은 전체 대화 1,999토큰, 요약과 최근 대화 1,744토큰이었다. 한도 2,300토큰에서 요약 방식은 3개 사실을 보존했고, 최근 대화만 사용한 방식은 0개였다. |
| ChatGPT(Codex) | 사용자와 고정 지시로 캐시 키를 만드는 방법과 TODO 코드 요청 | 사용자 ID, 줄바꿈, 고정 지시를 순서대로 합쳐 UTF-8로 인코딩하고 SHA-256으로 해시한다. 질문이 바뀌어도 사용자와 고정 지시가 같으면 키는 유지된다. | AI가 `cache_key`의 완성 코드를 채팅으로 제시했다. 현재 작업본에 이 방식이 반영되어 있다. | `run cache` 결과 생성, `check cache` 3/3 통과. `run cache --live`에서 첫 캐시 사용 시 1,228토큰 쓰기, 재사용 시 1,228토큰 읽기가 관측됐다. 기록된 입력 비용은 비사용 $0.0003066, 첫 사용 $0.000368, 재사용 $0.00008556이었다. |
| ChatGPT(Codex) | 필수 2 실행 명령과 `compare --live` 오류 해결 요청 | 명령은 `run`, 실행 항목은 `compare`, 실제 모델 호출 옵션은 `--live`라는 점을 확인했다. | 실행 명령을 `uv run --frozen python main.py run compare --live`로 바로잡았다. AI는 별도 OneDrive 사본에 빈 `.env`를 생성했다. | `C:\KANT` 작업본의 `artifacts/compare-live.json`과 `artifacts/cache-live.json`에서 실제 실행 결과를 확인했다. |

AI가 미작성 TODO의 완성 코드를 채팅으로 제시했고 예산 계산 줄도 한 차례 파일에 적용했다. 이 부분은 위 AI 활용 기준을 벗어난 사용으로 기록한다. 표의 실행 결과는 현재 과제 폴더에 저장된 검사 및 실행 산출물을 기준으로 적었다.
